# Data

Place the raw survey data file `public.csv` in this folder before running the
workflow.

**How to obtain:** download **Package 01** (Card & Krueger — minimum wage /
difference-in-differences) from the course project page (Google Drive), extract
the ZIP, and copy `public.csv` into this folder, keeping the filename unchanged.

**Usage:** for ECO6067 teaching and coursework only. Do not redistribute the
data, upload it to public repositories, or use it commercially.
